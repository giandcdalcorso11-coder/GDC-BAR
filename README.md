# SelfTap (nome di lavoro)

Birreria self-service: i clienti si spillano la birra da soli con un braccialetto NFC, le spillatrici elettroniche misurano i litri e il conto si paga in cassa a fine serata. **Progetto in fase di concept**, nessuna apertura pianificata.
